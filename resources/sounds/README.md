# SonaBar feedback sounds

These WAV files are original SonaBar tones generated by
`scripts/generate-feedback-sounds.ps1`. They contain no third-party samples.
The script uses simple sine segments with short fades so the assets can be
reproduced from source.

- `start.wav` — recording started
- `done.wav` — recording finished
- `error.wav` — dictation or insertion failed

The app maps them to the **Off**, **Minimal** and **Standard** sound modes.
