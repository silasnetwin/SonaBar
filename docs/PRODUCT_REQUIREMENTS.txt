6. SMART TEXT INSERTION
==================================================

This is EXTREMELY IMPORTANT.

SonaBar must reliably insert text into applications across Windows.

Create a robust multi-strategy insertion pipeline.

STRATEGY 1

Windows UI Automation.

Attempt direct insertion using supported UI Automation patterns.

STRATEGY 2

Clipboard insertion.

Temporarily place transcription into clipboard.

Send Ctrl+V using Windows SendInput.

Then restore the user's previous clipboard contents when configured.

STRATEGY 3

Unicode SendInput fallback if appropriate.

The app must remember which strategy works best for specific applications.

Create per-application profiles.

Examples:

Discord.exe
Code.exe
chrome.exe
msedge.exe
WINWORD.EXE
OUTLOOK.EXE

Never type into a detected password field.

Use UI Automation IsPassword or equivalent detection.
